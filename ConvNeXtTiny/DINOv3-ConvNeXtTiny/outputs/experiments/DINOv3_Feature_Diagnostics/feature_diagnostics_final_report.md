# DINOv3 特征机制诊断总报告

## 结论摘要

- R0→R1→R2 的 Macro-AUROC 点估计为 0.794882 → 0.799318 → 0.802116；Subject-cluster paired Bootstrap：R1−R0 +0.004436 [-0.014100, +0.021090]，R2−R1 +0.002798 [-0.005994, +0.010473]，R2−R0 +0.007234 [-0.010093, +0.021461]。
- R3 消融 Macro-AUROC：A R3 fused=0.804653，B R3 global-only=0.804485，C R2 GAP=0.802116；A−B=+0.000168，B−C=+0.002369，A−C=+0.002537（CI 见下文）。
- R3 Best Checkpoint 实际 alpha=0.05066201；A 复现历史 `val_best.csv` Macro-AUROC 差 0.00000000。
- A/B/C Macro-AUPRC=0.418717/0.418469/0.421206；各比较的 paired CI 见 20.2。
- Bootstrap 区间如包含 0，不足以确认所比较指标有方向性差异。分辨率效应仍受训练预算差异与 Best Epoch 选择影响；B−C 不证明局部分支训练期的因果作用。

## 20.1 分辨率带来了什么？

R2−R0 AUROC 点估计最高的三个类别：Pneumothorax (+0.0360), Enlarged Cardiomediastinum (+0.0349), Edema (+0.0105).
R2−R0 Macro-AUROC 的 95% CI 为 [-0.010093, +0.021461]。448 是否已足够、512 是否仍有稳定增益，应以 R2−R1 的区间和逐类变化共同判断，不从总体点估计外推到所有疾病。
R0 的 image budget / accumulation / best-epoch 累计更新数与 R1/R2 不同；R1/R2 的 checkpointing 也不同。故观察到的收益与高分辨率带来的采样细节保留相一致，但这组历史实验不能完全隔离分辨率本身的因果效应。

## 20.2 R3 改善了什么？

A−B（局部分支在推理融合中的直接增量）Macro-AUROC=+0.000168，95% CI=[-0.000091, +0.000428]。
B−C（R3 训练后的 Global-only 与独立 R2 GAP）Macro-AUROC=+0.002369，95% CI=[-0.004952, +0.009297]。
A−C 完整 R3 相对 R2 的 Macro-AUROC=+0.002537，95% CI=[-0.004813, +0.009448]。
Macro-AUPRC：A−B=+0.000249，95% CI=[-0.001304, +0.001127]；B−C=-0.002738，95% CI=[-0.016489, +0.008600]；A−C=-0.002489，95% CI=[-0.016354, +0.008684]。

## 20.3 局部响应是否合理？

Stage3 mask 在模型内部约束 Top-K；padding 像素在所选特征单元覆盖中的最大比例为 0.1896。类别响应图的 mean absolute inter-disease correlation 最高类别为 Pneumonia (0.672)。
抽查的 Atelectasis 高分与 Pneumonia 低分图中，响应分布较宽，Top-K 有时覆盖图像边缘或文字/设备标记附近；多视角 Study 的响应随视角明显变化，未见稳定的跨视角焦点。该结论仅来自展示样本。
这些统计和真实诊断图仅描述模型内部响应结构。没有肺野分割/病灶标注，不能据此宣称定位到肺组织或真实病灶；高/低熵也不等同于好/坏。具体样本需结合 `r3_response_visualizations/` 人工核查。

## 20.4 下一步模型路线

- 路线 A（普通 GAP）：若局部分支没有可确认的直接增益，或响应检查发现明显边界/伪相关，保留 R2 GAP 作为主模型。
- 路线 B（优化局部响应）：若 A−B 有稳定正向证据，且响应经独立区域标注验证后，再研究 Top-K 或局部池化方式。
- 路线 C（训练期局部辅助）：若 B−C 有稳定增益而 A−B 直接作用较弱，后续可独立训练检验训练期辅助分支。

- 现有验证证据不足以在 A/B/C 三条路线中做确认性选择。保留 R2 GAP 作为稳健参照；下一轮需预先定义假设并用独立种子/独立测试证据验证。
- 本次没有训练、优化器更新、模型权重修改、学习率搜索或 Test 数据访问。
