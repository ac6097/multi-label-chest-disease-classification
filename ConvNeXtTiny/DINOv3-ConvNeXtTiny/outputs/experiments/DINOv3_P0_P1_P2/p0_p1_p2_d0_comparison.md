## 结论

- P0/P1/P2 中观测 Macro-AUROC 最高的是 **P2**（0.794882）。是否优于相邻冻结范围，应结合配对区间而不是只看点估计。
- 历史 V1 Macro-AUROC 为 0.795395，与本实验不是严格匹配的预训练消融。
- 冻结深度对过拟合、类别变化和速度的判断见曲线图、逐类 CSV、每组 `report.md` 与 `gpu_benchmark_comparison.md`。
- 本文不以验证集结果替代独立 Test 评估。

## 对方案问题的直接回答

1. **P0 线性可分性：** Head-only 最佳 Macro-AUROC 为 0.709145（Epoch 18）。
2. **解冻 Stage 4：** P1−P0 为 +0.057047，95% CI [+0.038478, +0.073071]。
3. **继续解冻 Stage 3：** P2−P1 为 +0.028691，95% CI [+0.017655, +0.040313]；P2−P0 为 +0.085738，95% CI [+0.067023, +0.103040]。
4. **最高点估计：** P2 为 0.794882；是否超过 0.80：False。
5. **验证稳定性描述：** 以峰值到停止轮 Macro-AUROC 的下降量衡量，当前最小的是 P0（下降 0.000182）；各组停止轮和 Valid BCE 变化见逐组报告。
6. **Pneumonia：** P0/P1/P2 相对 D0 AUROC 差值分别为 -0.126366 / -0.058879 / +0.002175。
7. **Lung Opacity：** P0/P1/P2 相对 D0 AUROC 差值分别为 -0.059762 / -0.030472 / +0.001239。
8. **实际效率：** 正式 epoch images/s 在上表；所选 Benchmark 配置的稳定长测均值见 `gpu_benchmark_comparison.md`，两种计时分别报告。
9. **训练/验证分离：** 比较每组 Train BCE、Valid BCE、Macro-AUROC 曲线及动态停止轮；早停只有三条件同时成立才触发。
10. **额外解冻的收益/成本：** 联合对照各组最佳 Macro-AUROC、Subject 配对 CI、实际 images/s 和可训练参数数量；不以单一点估计宣称收益。
