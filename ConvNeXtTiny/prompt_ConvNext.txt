
# Codex 任务：ConvNeXt-Tiny 多尺度特征与空间信息保留实验

## 一、实验背景与目标

当前项目为胸部 X 光片十类别多标签疾病分类，使用 ConvNeXt-Tiny ImageNet 预训练 Backbone，最终按照 Study 级 Logit Mean 融合输出疾病概率。

此前已经进行了以下实验：

1. 原始 ConvNeXt-Tiny + GAP 分类头。
2. 调整 Backbone 和分类头学习率。
3. Linear Warmup + Cosine Annealing。
4. Disease-Specific Attention Pooling。
5. 二维正弦余弦位置编码。
6. Relative Position Bias 空间 Self-Attention。
7. 缩短余弦退火周期的完整训练实验。

目前 Validation Macro-AUROC 大致集中在 0.78–0.79，增加复杂注意力分类头尚未带来稳定提升。

另外，此前 DenseNet121 曾尝试 Dense Block 2/3/4 的多尺度 GAP 向量拼接，验证集 Macro-AUROC 从约 0.7888 下降至 0.7704。

因此，本轮实验不再增加 Transformer、Disease Query 或类别关系建模，而是重新研究 ConvNeXt 对胸片图像特征的提取及空间信息保留能力。

本轮重点检验两个假设：

**假设 A：标准 GAP 将空间特征直接平均，可能损失与疾病诊断有关的局部区域分布信息。**

**假设 B：仅使用 ConvNeXt Stage 4 的高级特征，可能没有充分利用 Stage 3 中较高分辨率的局部病理特征。**

为此，分别进行 A1、B1、C1 三组独立实验，并与原始 ConvNeXt-Tiny + GAP 基线进行比较。

## 二、实验组设计

### A0：原始 ConvNeXt-Tiny + GAP 基线

基线结构：

Input → ConvNeXt Stage 1/2/3/4 → GAP → LayerNorm → Linear(10)

采用原始 ConvNeXt-Tiny 结构，不增加额外注意力模块。

320×320 输入条件下，最后的 Stage 4 特征通常为：

F4 ∈ R[B,768,10,10]

经过 GAP：

z ∈ R[B,768]

再通过十分类线性层获得：

Logits ∈ R[B,10]

要求首先核对已有基线的训练配置及权重。如果历史 GAP 基线与本轮使用相同数据、预处理、损失函数、学习率、调度器和验证口径，可以保留其结果作为对照。

如果存在明显配置差异，则应在相同实验条件下重新训练 A0，使四组实验具备严格可比性。

历史基线结果仍然保留作为额外参考，但不能与严格控制变量的基线混为一谈。

### A1：ConvNeXt Stage 4 + Spatial Pyramid Pooling

本实验只改变原始 GAP 的空间聚合方式，不改变 Backbone。

完整结构：

Input → ConvNeXt Stage 4 → SPP → Linear(10)

SPP 使用两级池化：

第一级：Adaptive Average Pooling(1×1)

第二级：Adaptive Average Pooling(2×2)

对于 Stage 4 特征 F4：

z_global = GAP(F4)

输出：

[B,768]

z_regional = AdaptiveAvgPool2d(F4,2×2)

Flatten 后：

[B,3072]

拼接：

z = Concat(z_global,z_regional)

最终：

[B,3840]

接十分类线性层：

Linear(3840,10)

可以使用必要的特征归一化，但不引入额外注意力或大型 MLP。

实验需要明确：

- 原始 GAP 的 1×1 全局分支必须保留。
- 2×2 区域特征能够保留粗粒度空间分布。
- 不加入 Self-Attention。
- 不加入 Disease Query。
- 不加入 Relative Position Bias。
- 不改变 Stage 4 的卷积结构。
- SPP 使用固定的平均池化，不加入可学习空间权重。

本组主要回答：

**在 Stage 4 特征保持不变时，保留粗粒度空间分布能否提高 Macro-AUROC？**

### B1：ConvNeXt Stage 3 + Stage 4 空间特征融合

本实验研究多尺度特征提取。

注意：这次不允许采用以前 DenseNet 实验中的“不同 Stage 分别 GAP，再拼接向量”的做法。

必须在二维空间特征图层面完成融合。

以 320×320 输入为例：

Stage 3：

F3 ∈ R[B,384,20,20]

Stage 4：

F4 ∈ R[B,768,10,10]

先对两个分支分别进行 1×1 卷积通道投影：

F3_proj = Conv1x1(F3,384→256)

F4_proj = Conv1x1(F4,768→256)

得到：

F3_proj ∈ R[B,256,20,20]

F4_proj ∈ R[B,256,10,10]

使用双线性插值，把 Stage 4 特征上采样至 Stage 3 的分辨率：

F4_up ∈ R[B,256,20,20]

然后沿通道维度进行拼接：

F_concat = Concat(F3_proj,F4_up)

得到：

F_concat ∈ R[B,512,20,20]

再使用轻量 1×1 卷积融合不同阶段的特征：

F_fused = Conv1x1(F_concat,512→256)

配合必要的归一化与 GELU：

F_fused ∈ R[B,256,20,20]

最终采用标准 GAP：

GAP(F_fused) → Linear(256,10)

要求：

1. Stage 3 和 Stage 4 特征必须从同一个 ConvNeXt Backbone 的真实前向过程获取。
2. 不允许重复运行两次 Backbone。
3. Stage 4 上采样仅负责特征分辨率对齐，不得声称上采样能够创造新的细节。
4. 细粒度信息来自 Stage 3 的真实特征。
5. 优先使用轻量投影与融合，避免大幅增加参数量。
6. 不加入 DSAP、Transformer 或额外的类别注意力机制。
7. 不修改预训练 Stage 内部的 ConvNeXt Block。
8. 输出仍然是十个独立疾病 Logits。

本组主要回答：

**在最终仍然使用 GAP 的情况下，加入 Stage 3 的细粒度特征能否改善疾病识别？**

### C1：Stage 3 + Stage 4 空间融合 + SPP

这一组将 A1 与 B1 两种方法结合起来。

结构为：

Input → ConvNeXt Stage 3/4 → 空间特征融合 → SPP → Linear(10)

其中 Stage 3/4 的空间融合模块必须与 B1 完全一致。

即：

F3_proj ∈ R[B,256,20,20]

F4_up ∈ R[B,256,20,20]

Concat → Conv1x1 → Norm/GELU

得到：

F_fused ∈ R[B,256,20,20]

随后使用与 A1 相同的池化策略：

AdaptiveAvgPool2d(1×1)

得到：

[B,256]

AdaptiveAvgPool2d(2×2)

Flatten 后：

[B,1024]

拼接：

z ∈ R[B,1280]

最终：

Linear(1280,10)

要求：

- 多尺度空间融合实现与 B1 一致。
- SPP 实现与 A1 一致。
- 不再加入其他额外网络模块。
- B1 和 C1 使用相同的融合输出维度。
- 两组实验分别从相同来源的预训练权重初始化，不直接继承另一实验训练后的权重。

本组主要回答：

**多尺度空间特征融合与空间金字塔池化是否具有互补作用？**

需要特别说明，A1、B1、C1 的分类器输入维度不同，这是结构实验的必要差异，但需要记录新增参数量及计算开销，避免忽略模型容量变化。

## 三、训练配置统一

三组新实验和必要时重新训练的 A0 基线，都必须使用统一配置。

### 1. 训练周期

总训练轮数：

epochs = 20

Warmup：

warmup_epochs = 2

Cosine Annealing：

cosine_epochs = 18

训练策略：

Epoch 1–2：Linear Warmup

Epoch 3–20：Cosine Annealing

不设置 Epoch 21–40 的低学习率保持阶段。

学习率在第 20 个 Epoch 结束时衰减至预设最低值，实验随之结束。

### 2. 学习率

Backbone 峰值学习率：

1e-5

新增分类头及融合模块峰值学习率：

2e-4

最低学习率沿用上一轮实验：

Backbone min_lr = 5e-7

Head min_lr = 1e-5

四组实验使用相同的学习率调度形式和参数。

Scheduler 应按真实 optimizer update 正确推进，兼容梯度累积。

绘制完整的 Backbone LR 与 Head LR 曲线。

必须完成所有 20 Epoch，以观察完整训练过程以及过拟合趋势。

- last.pth：Epoch 20 的 checkpoint。

所有 checkpoint 都保存在对应实验独立目录，不允许覆盖已有实验。

## 十、最终需要回答的问题

本轮实验的目的不是单纯获得更高分数，而是明确识别当前 ConvNeXt-Tiny 在胸片识别任务中的潜在结构瓶颈。

最终必须回答：

**问题一：Stage 4 的标准 GAP 是否限制了模型对空间分布信息的利用？**

**问题二：Stage 3 + Stage 4 的二维空间特征融合，是否比单独使用 Stage 4 更有效？**

**问题三：多尺度空间融合与 SPP 结合，是否能获得超越单独模块的收益？**

**问题四：哪些疾病从空间特征改造中受益最多，尤其是 Pneumonia 和 Lung Opacity？**

**问题五：空间特征结构改变后，过拟合是否仍然存在，且是否影响最佳验证 Macro-AUROC？**

最终依据实测结果决定后续网络结构，不预设任何一组一定优于原始 ConvNeXt。
